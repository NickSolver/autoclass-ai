# ADR-0005. Провайдеры распознавания речи

- **Статус:** принято
- **Дата:** 24.10.2026
- **Связано с:** ADR-0004; ТЗ, разд. 4.3, 8, 12

## Решения

1. Драйвер добавляется только после сверки с **официальной** спецификацией API. Документация сайтов
   провайдеров из сети заказчика по большей части недоступна, поэтому источники — официальные репозитории:

   | Сервис | Драйвер | Источник спецификации |
   |---|---|---|
   | Яндекс SpeechKit | `yandex` | `yandex-cloud/cloudapi`: `ai/stt/v3/stt.proto`, `stt_service.proto`, `operation/*.proto` |
   | T-Bank VoiceKit | `tbank` | `Tinkoff/voicekit-examples`: `apis/tinkoff/cloud/stt/v1`, `longrunning/v1`, `python/auth.py` |
   | OpenAI | `openai` | `openai/openai-openapi`: `createTranscription`, схемы diarized/verbose JSON |

   Проверено на подменённой сети по формам из спецификаций (`tests/Feature/AsrDriversTest.php`).
   **На живом API каждый драйвер проверяется при первом ключе** (кнопка «Проверить» и первый звонок).

2. **Не подключены, видны как «ожидает документации»** (выбрать нельзя):
   - SaluteSpeech (Сбер) — в официальном репозитории только потоковый gRPC; REST-описание распознавания файлов
     и серверы Сбера из сети недоступны;
   - МТС Audiogram — публичной спецификации нет;
   - ЦРТ — публично только beta-gRPC 2022 г.; актуальная документация недоступна;
   - Google Speech-to-Text — синхронное распознавание только до 1 минуты, длинным звонкам нужен Google Cloud Storage.
     **Скрыт из интерфейса по решению заказчика (24.10.2026)**, запись в реестре сохранена.

3. **Стерео сохраняется.** Нормализованная копия — моно (для единообразия), но многоканальные провайдеры
   (Яндекс, T-Bank) получают каналы оригинала: в телефонной записи сотрудник и клиент часто на разных
   каналах — это самое надёжное разделение говорящих. Для моно у Яндекса включается его разметка говорящих;
   у T-Bank в моно говорящие не различаются; OpenAI различает говорящих только моделью gpt-4o-transcribe-diarize.
4. **Метки говорящих** приводятся к S1, S2… по порядку появления во времени; роль (сотрудник/клиент) — гипотеза
   модели оценки, не установление личности.
5. **Ключи:** у T-Bank два (API-ключ и секретный, JWT HS256) — хранятся зашифрованным JSON; у остальных один.
   Ошибки 401/403/402 — без повторов; 429 и 5xx — повтор; ключи вычищаются из сообщений провайдеров.
6. **Аудио для провайдера** готовится ffmpeg (только локальные файлы): Яндекс — OGG/Opus, T-Bank — MP3 16 кГц,
   OpenAI — MP3 моно (лимит OpenAI — 25 МБ на файл).

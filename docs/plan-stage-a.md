# План этапа A — FOUNDATION

Исходные условия: пустой репозиторий с Docker-окружением (PHP 8.3-FPM, MySQL 8.4, nginx).
PHP/Composer есть только в контейнере `app`; Node.js — на хосте.

| # | Шаг | Результат |
|---|-----|-----------|
| 1 | Laravel 13 + Vue 3 + TS + Vite + Pinia + Router + Tailwind, линтеры (Pint, Larastan, ESLint, vue-tsc), Vitest, PHPUnit на отдельной MySQL-базе `laravel_test`, CI | Каркас, который собирается и тестируется |
| 2 | ADR-0001: оргструктура, `User`/`Employee`, RBAC с областями | `docs/adr/0001-rbac-and-org-scope.md` |
| 3 | Миграции: оргструктура, сотрудники и назначения, пользователи, роли, права, назначения ролей, сессии, аудит | Обратимые миграции |
| 4 | Ядро доступа: реестр прав, `AccessScope`, `AccessResolver`, Policies, трейт `HasOrgScope`, защита от эскалации | Серверная авторизация с запретом по умолчанию |
| 5 | Аутентификация: вход по логину, выход, ограничение попыток, сброс пароля по одноразовой ссылке, принудительная смена временного пароля, список/завершение сессий, без публичной регистрации; команда `avtoklass:create-superadmin` | `/api/v1/auth/*` |
| 6 | API справочников: группы, компании, центры, отделы, сотрудники и назначения, пользователи, роли, права, аудит | `/api/v1/*`, OpenAPI (Scramble) |
| 7 | UI: вход, каркас с меню и хлебными крошками, профиль и сессии, справочники, пользователи, роли и матрица прав, аудит, страницы недоступных модулей | SPA |
| 8 | Сидеры: синтетическая группа, компании, пользователи с разными ролями — без реальных ПДн | `php artisan db:seed` |
| 9 | Тесты: изоляция компаний A/B через API, эскалация прав, вход/выход/сброс/сессии, миграции up/down | `php artisan test`, `npm test` |

Вне этапа A (не делается): телефония, загрузка звонков, ASR/LLM, конструкторы процессов
и чек-листов, аналитика, MFA, Redis/Horizon.
